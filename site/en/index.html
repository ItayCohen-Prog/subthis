Install from zero

Nothing on your computer yet? That's fine. These steps assume a blank machine and take about five minutes.

It looks like you're on … — wrong? Pick another tab.

  1. Open a terminal

    Press the Windows key, type powershell, press Enter.

  2. Install uv (it brings Python with it)

    powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

    Close PowerShell and open it again so it learns the new command.

  3. Install ffmpeg (reads the sound from videos)

    winget install --id Gyan.FFmpeg -e

  4. Install subthis and run setup

    uv tool install subthis
subthis setup

    Setup walks you through getting an OpenAI key, step by step, even if you've never used it before.

How it works

Two transcriptions are better than one. subthis runs both and merges the best of each.

00:00 → 00:20

Listen twice

The audio goes to OpenAI twice: one model for the most accurate wording, another for exact word-by-word timing.

00:20 → 00:40

Align every word

The accurate words get matched to the precise timestamps, so "OpenAI" lands exactly where the speaker said it, even when the timing model heard "אופן איי איי".

00:40 → done

Write short cues

Words are grouped into cues of at most three, timed to hold across pauses, and written as a clean .srt file next to your video.

What you get

Hebrew meets English

Terms you teach

Add your own names and phrases per run, per folder, or globally, with an interactive editor for the saved list.

Setup that guides

First time with the OpenAI API? Setup walks you to a key and five dollars of credit, and tests the key before saving it.

Errors that help

A revoked key or an empty balance produces a plain sentence with the exact link to fix it, not a stack trace.

Updates offer themselves

When a new version ships, subthis asks once, updates, and reruns your exact command from where you were.

Long videos welcome

Hours-long recordings get chunked, transcribed, and merged automatically, staying under upload limits.

subthis turns a video into subtitles. This one-time setup takes about
two minutes. Nothing on your computer is changed except subthis's own
settings folder: ~/.config/subthis

  ✓ ffmpeg is installed (subthis uses it to read the sound from your videos)

subthis sends your video's audio to OpenAI (the company behind ChatGPT)
to turn the speech into text. For that you need your own OpenAI key:
a long code starting with sk- that acts like a password. It is saved
only on this computer.

Here's what happens next:
  1. OpenAI's key page opens in your browser.
  2. Click 'Create new secret key', then 'Copy'.
  3. Come back here and paste it.

Press Enter to open the key page in your browser...
    https://platform.openai.com/api-keys
