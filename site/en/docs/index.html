subthis documentation

subthis turns a video (or audio file) into an SRT subtitle file with short, accurately worded captions, at most three words per cue. It is built for Hebrew speech with English names and jargon mixed in. A machine-readable copy of these docs lives at /docs.md and /llms.txt.

1. Install

subthis needs two things on your computer: uv (which installs subthis and Python itself) and ffmpeg (which reads the audio out of video files). Both are one command per OS.

Windows (PowerShell)

powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
winget install --id Gyan.FFmpeg -e
uv tool install subthis

Open a new PowerShell window after installing uv so the command is found.

macOS (Terminal)

curl -LsSf https://astral.sh/uv/install.sh | sh
brew install ffmpeg
uv tool install subthis

If Homebrew is missing, install it first from brew.sh.

Linux

curl -LsSf https://astral.sh/uv/install.sh | sh
sudo apt install ffmpeg   # or dnf / pacman, per your distribution
uv tool install subthis
If subthis is not found after installing, run uv tool update-shell (or pipx ensurepath if you used pipx) and open a new terminal.

2. Setup

subthis setup

Setup is a guided, one-time wizard. It:

  • checks that ffmpeg is installed, and tells you how to install it if not;
  • explains each step before touching your browser: pressing Enter opens OpenAI's key page (no account yet? the site signs you up first) with click-by-click instructions for creating and copying a key;
  • tests the key you paste immediately: an invalid or revoked key re-prompts, an account with no credit gets click-by-click guidance for adding the 5-dollar minimum of prepaid credit (roughly five hours of video) and a re-check;
  • saves the key to subthis's own settings folder (~/.config/subthis on Linux and macOS, %APPDATA%\subthis on Windows) and nowhere else.

An OPENAI_API_KEY environment variable, if set, overrides the stored key.

3. Make subtitles

subthis lecture.mp4

That writes lecture.srt next to the video and prints the full path when done. Tip for the terminal-shy: type subthis  then drag the video file into the terminal window and press Enter.

Options

subthis talk.mp4 -o subs/talk.srt      # choose the output path
subthis clip.mp4 --max-words 2         # shorter cues (1, 2 or 3)
subthis clip.mp4 --language he --language en   # expected languages
subthis clip.mp4 --force               # overwrite an existing .srt

Long videos are split into chunks, transcribed, and merged automatically. Each chunk goes to OpenAI twice: gpt-transcribe for the most accurate wording and whisper-1 for word-level timing; subthis aligns the two so accurate words carry precise timestamps.

4. Teach it terms

Terms are names and jargon subthis should spell correctly (and keep in English inside Hebrew speech). The syntax is the same everywhere: spaces separate terms, single quotes group a multi-word term.

subthis clip.mp4 --term "Omarchy 'Wispr Flow'"    # this run only
subthis config terms "Omarchy 'Wispr Flow'"       # saved, every video
subthis config terms                               # interactive editor

The interactive editor lists your saved terms with a key guide at the bottom: arrows move, space selects, m marks or unmarks all, r removes the selected terms after a confirmation, a adds new ones, q saves and quits.

Per-folder terms

Put a file named subthis-terms.txt next to your videos and it is picked up automatically for any video in that folder. One term per line; spelling corrections use aliases:

MyCompany
DaVinci Resolve = דה וינצ'י ריזולב | Davinci Resolve

5. Config

CommandWhat it does
subthis config keyReplace the saved OpenAI key. The new key is verified (validity and credit) before saving, exactly like in setup. Keys are never accepted as command-line arguments.
subthis config termsOpen the interactive terms editor; with a quoted string argument, append terms directly.
subthis config open onAfter finishing, also open your file manager with the subtitle file selected (Explorer, Finder, or the Linux FileManager1 interface). off turns it back off.
subthis config captionsView and tune caption behavior; saved for every future video, defaults match subtitle-industry standards. Settings: words per line (1-3), pause (a silence this long starts a new line), hang (how long a line outlives its last word), min (minimum time on screen), gap (empty space before the next line, default 0; all in seconds), punctuation keep|remove, and silence hold|cut (hold keeps a line up through silences). reset restores the defaults. Example: subthis config captions words 2.

6. Updates

At the start of an interactive run, subthis checks PyPI (three-second budget, silent when offline). If a newer version exists it asks once. Answer yes and it updates itself and reruns your exact command; answer no and it prints the command to update later. On Windows the running program cannot replace itself, so subthis prints the command for you to run in a fresh window:

uv tool upgrade subthis

7. Troubleshooting

"subthis: command not found" after installing

Run uv tool update-shell (or pipx ensurepath), then open a new terminal window.

"OpenAI no longer accepts your saved key"

The key was revoked or deleted. Run subthis config key and paste a fresh key from platform.openai.com/api-keys.

"Your OpenAI account is out of credit"

Add credit at the billing page (5 dollars minimum) and run subthis again.

"Required command not found: ffmpeg"

Install ffmpeg for your OS (see Install), then rerun. subthis setup prints the exact command for your system.

"The video may have no audio track"

The file has no sound to transcribe. Check it plays with audio in a media player.

8. CLI reference

Command / flagMeaning
subthis <video>Transcribe a video or audio file to <video>.srt.
subthis setupGuided one-time setup: ffmpeg check, OpenAI key with live validation.
subthis config key|terms|openChange the key, edit saved terms, toggle open-folder-when-done.
subthis help / subthisFull help with an OS-specific quick start.
subthis docsOpen this documentation in the browser.
-o, --output PATHOutput SRT path (default: next to the input).
--max-words {1,2,3}Maximum words per cue. Default 3.
--term "A 'B C'"Extra terms for this run; single quotes group multi-word terms. Repeatable.
--terms-file PATHAlternative global terms file.
--language XXExpected ISO-639-1 language; repeat for code-switching. Default: he, en.
--forceOverwrite an existing subtitle file.
--versionPrint the version.

Exit codes: 0 success, 1 a handled error (message on stderr, prefixed subthis:), 130 cancelled with Ctrl+C.

9. For AI agents

If you are an AI agent operating a computer for a user: subthis is non-interactive-safe. Piped stdin disables all prompts, colors, and browser openings; the update check is skipped when stdin is not a TTY, and can be disabled explicitly with SUBTHIS_SKIP_UPDATE=1. The canonical machine-readable summary is at https://subthis.webivize.com/llms.txt, and the full docs as markdown at https://subthis.webivize.com/docs.md.

# minimal agent flow
uv tool install subthis
OPENAI_API_KEY=sk-... subthis input.mp4 -o output.srt --force
# stdout ends with the absolute path of the written file
