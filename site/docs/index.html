התיעוד של subthis

subthis הופך סרטון (או קובץ אודיו) לקובץ כתוביות SRT עם שורות קצרות ומנוסחות במדויק, עד שלוש מילים בשורה. בנוי לדיבור בעברית עם שמות ומונחים באנגלית. עותק קריא-מכונה של התיעוד נמצא ב‑‎/docs.md‎ וב‑‎/llms.txt‎.

1. התקנה

subthis צריך שני דברים על המחשב: uv (שמתקין את subthis ואת פייתון עצמו) ו‑ffmpeg (שקורא את האודיו מקובצי וידאו). שניהם פקודה אחת לכל מערכת.

Windows (PowerShell)

powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
winget install ffmpeg
uv tool install subthis

אחרי התקנת uv פתחו חלון PowerShell חדש כדי שהפקודה תזוהה.

macOS (Terminal)

curl -LsSf https://astral.sh/uv/install.sh | sh
brew install ffmpeg
uv tool install subthis

‏אם אין Homebrew, התקינו אותו קודם מ‑brew.sh.

Linux

curl -LsSf https://astral.sh/uv/install.sh | sh
sudo apt install ffmpeg   # או dnf / pacman לפי ההפצה
uv tool install subthis
אם אחרי ההתקנה הפקודה subthis לא נמצאת, הריצו uv tool update-shell (או pipx ensurepath אם התקנתם עם pipx) ופתחו טרמינל חדש.

2. הגדרה

subthis setup

ההגדרה היא אשף מודרך חד-פעמי. הוא:

  • בודק ש‑ffmpeg מותקן, ואם לא — אומר בדיוק איך להתקין;
  • שואל אם השתמשתם בעבר ב‑API של OpenAI — ענו לא והוא ילווה אתכם ביצירת חשבון, הוספת 5 דולר קרדיט (המינימום; מספיק לבערך חמש שעות וידאו) ויצירת מפתח, ופותח כל דף בדפדפן;
  • בודק את המפתח מיד: מפתח שגוי או מבוטל מבקש הקלדה מחדש, וחשבון בלי קרדיט מקבל קישור לדף החיוב ובדיקה חוזרת;
  • שומר את המפתח רק בתיקיית ההגדרות של subthis‏ (‎~/.config/subthis בלינוקס ומק, %APPDATA%\subthis בווינדוס).

משתנה סביבה OPENAI_API_KEY, אם מוגדר, גובר על המפתח השמור.

3. יצירת כתוביות

subthis lecture.mp4

זה כותב lecture.srt ליד הסרטון ומדפיס בסוף את הנתיב המלא. טיפ: הקלידו subthis  וגררו את קובץ הווידאו לתוך חלון הטרמינל, ואז Enter.

אפשרויות

subthis talk.mp4 -o subs/talk.srt      # לבחור נתיב פלט
subthis clip.mp4 --max-words 2         # שורות קצרות יותר (1, 2 או 3)
subthis clip.mp4 --language he --language en   # שפות צפויות
subthis clip.mp4 --force               # לדרוס קובץ ‎.srt קיים

סרטונים ארוכים נחתכים, מתומללים וממוזגים אוטומטית. כל מקטע נשלח ל‑OpenAI פעמיים: gpt-transcribe לניסוח המדויק ו‑whisper-1 לתזמון ברמת מילה; subthis מיישר בין השניים.

4. לימוד מונחים

מונחים הם שמות וביטויים ש‑subthis צריך לאיית נכון (ולהשאיר באנגלית בתוך דיבור עברי). התחביר זהה בכל מקום: רווחים מפרידים בין מונחים, גרש בודד מקבץ מונח מרובה מילים.

subthis clip.mp4 --term "Omarchy 'Wispr Flow'"    # להרצה הזו בלבד
subthis config terms "Omarchy 'Wispr Flow'"       # נשמר לכל הסרטונים
subthis config terms                               # עורך אינטראקטיבי

העורך האינטראקטיבי מציג את המונחים השמורים עם מדריך מקשים בתחתית: חצים לתנועה, רווח לבחירה, m לסימון או ביטול של הכול, r להסרה עם אישור, a להוספה, q לשמירה ויציאה.

מונחים לתיקייה

שימו קובץ בשם subthis-terms.txt ליד הסרטונים והוא ייקלט אוטומטית לכל סרטון באותה תיקייה. מונח בכל שורה; תיקוני איות עם כינויים:

MyCompany
DaVinci Resolve = דה וינצ'י ריזולב | Davinci Resolve

5. הגדרות

פקודהמה היא עושה
subthis config keyהחלפת מפתח OpenAI השמור. המפתח החדש נבדק (תקינות וקרדיט) לפני השמירה, בדיוק כמו בהגדרה. מפתחות לעולם לא מתקבלים כארגומנט בשורת הפקודה.
subthis config termsפתיחת עורך המונחים; עם מחרוזת בגרשיים — הוספה ישירה.
subthis config open onבסיום, לפתוח גם את סייר הקבצים עם קובץ הכתוביות מסומן. off מכבה.
subthis config captionsצפייה וכוונון של התנהגות הכתוביות; נשמר לכל הסרטונים הבאים, וברירות המחדל לפי תקני תעשיית הכתוביות. ההגדרות: words מילים בשורה (1–3), pause (שקט באורך כזה פותח שורה חדשה), hang (כמה זמן שורה נשארת אחרי המילה האחרונה), min (זמן מינימלי על המסך, הכול בשניות), punctuation keep|remove, ו‑silence hold|cut (‏hold משאיר שורה על המסך גם בשקט). reset מחזיר לברירות המחדל. דוגמה: subthis config captions words 2.

6. עדכונים

בתחילת הרצה אינטראקטיבית subthis בודק את PyPI (תקציב של שלוש שניות, שקט כשאין רשת). אם יש גרסה חדשה הוא שואל פעם אחת. ענו כן — והוא מתעדכן ומריץ מחדש בדיוק את הפקודה שלכם; ענו לא — והוא מדפיס את פקודת העדכון להמשך:

uv tool upgrade subthis

7. פתרון תקלות

‏"subthis: command not found" אחרי התקנה

הריצו uv tool update-shell (או pipx ensurepath) ופתחו טרמינל חדש.

‏"OpenAI no longer accepts your saved key"

המפתח בוטל או נמחק. הריצו subthis config key והדביקו מפתח חדש מ‑platform.openai.com/api-keys.

‏"Your OpenAI account is out of credit"

הוסיפו קרדיט בדף החיוב (מינימום 5 דולר) והריצו שוב.

‏"Required command not found: ffmpeg"

התקינו ffmpeg לפי המערכת שלכם (ראו התקנה). subthis setup מדפיס את הפקודה המדויקת למערכת שלכם.

‏"The video may have no audio track"

לקובץ אין סאונד לתמלל. בדקו שהוא מתנגן עם שמע בנגן מדיה.

8. מדריך פקודות

פקודה / דגלמשמעות
subthis <video>תמלול קובץ וידאו או אודיו ל‑<video>.srt.
subthis setupהגדרה מודרכת חד-פעמית: בדיקת ffmpeg, מפתח OpenAI עם אימות חי.
subthis config key|terms|openהחלפת מפתח, עריכת מונחים, פתיחת תיקייה בסיום.
subthis help / subthisעזרה מלאה עם התחלה מהירה לפי מערכת ההפעלה.
subthis docsפתיחת התיעוד הזה בדפדפן.
-o, --output PATHנתיב קובץ הפלט (ברירת מחדל: ליד הקלט).
--max-words {1,2,3}מקסימום מילים בשורה. ברירת מחדל 3.
--term "A 'B C'"מונחים להרצה הזו; גרש בודד מקבץ מונח מרובה מילים. ניתן לחזור על הדגל.
--terms-file PATHקובץ מונחים גלובלי חלופי.
--language XXשפה צפויה (ISO-639-1); חזרו על הדגל לשילוב שפות. ברירת מחדל: he, en.
--forceדריסת קובץ כתוביות קיים.
--versionהדפסת הגרסה.

קודי יציאה: 0 הצלחה, 1 שגיאה מטופלת (הודעה ב‑stderr עם התחילית subthis:), 130 ביטול עם Ctrl+C.

9. לסוכני AI

אם אתם סוכן AI שמפעיל מחשב עבור משתמש: subthis בטוח להרצה לא-אינטראקטיבית. קלט מנותב (pipe) מכבה את כל השאלות, הצבעים ופתיחת הדפדפן; בדיקת העדכון מדולגת כשאין TTY, ואפשר לכבות אותה מפורשות עם SUBTHIS_SKIP_UPDATE=1. הסיכום הקריא-מכונה נמצא ב‑llms.txt והתיעוד המלא כ‑markdown ב‑docs.md.

# minimal agent flow
uv tool install subthis
OPENAI_API_KEY=sk-... subthis input.mp4 -o output.srt --force
# stdout ends with the absolute path of the written file
